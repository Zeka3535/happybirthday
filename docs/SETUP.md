# Как подготовить квест в квартире

Квест устроен так: **подарок один**, но чтобы дойти до него, нужно пройти цепочку.

```
задание на сайте → подсказка, где искать → записка со словом в квартире
        ↑                                              │
        └──────── ввод слова на сайте ←────────────────┘
```

Каждое найденное слово — часть фразы. В финале из них складывается предложение,
и там же написано, где лежит подарок.

## Что нужно подготовить

- Подарок.
- Распечатанные записки (по одной на главу).
- 5–7 минут, чтобы разложить их по местам.
- Телефон под рукой — для проверки.

## Шаг 1. Заполнить контент

Откройте `js/config.js` и замените:

- `meta.heroText` — вступление;
- `meta.finalMessage` и `meta.signature` — письмо и подпись;
- `meta.giftPlace` — где реально будет лежать подарок;
- `levels[].title`, `prompt`, `hint` — задания и подсказки;
- `levels[].reward.text` — куда идти за запиской (это читает она);
- `levels[].reward.key` — слово, которое написано на записке;
- `levels[].reward.keyHint` — мягкая подсказка, если слово не сходится.

Слова-ключи должны складываться в осмысленную фразу **в порядке глав**.
Например: «КАЖДЫЙ ДЕНЬ С ТОБОЙ ДЕЛАЕТ МЕНЯ СЧАСТЛИВЫМ».
Если на записке два слова (`"С ТОБОЙ"`), на сайте нужно ввести оба.

Количество глав движок берёт из массива `levels`: можно оставить три, добавить
седьмую или убрать лишнюю. Главное — чтобы слова складывались в фразу.

## Шаг 2. Распечатать записки

1. Запустите сервер в папке проекта:
   ```powershell
   cd C:\Users\evgen\Downloads\happybirthday-2026
   python -m http.server 8080
   ```
2. Откройте `http://127.0.0.1:8080/docs/notes.html`.
3. Нажмите «Печать». На листе будут карточки с крупными словами.
4. Разрежьте на отдельные записки.

Внизу страницы есть таблица для вас: какое слово и куда прятать. **Не печатайте
её для неё** — это шпаргалка организатора.

Если в шапке страницы видно предупреждение про демо — значит, в конфиге ещё
стоит `meta.demo: true` или не заменены ключи.

## Шаг 3. Разложить записки

Раскладывайте **по порядку глав**, каждую — в то место, которое описано
в `reward.text` этой главы.

Пример для этого набора:

| # | Куда спрятать | Слово |
|---|----------------|-------|
| 1 | у имперского разрушителя из Lego | КАЖДЫЙ |
| 2 | в книге «Мечтают ли андроиды об электроовцах?» | ДЕНЬ |
| 3 | в коробке от игры «Предназначение» | С ТОБОЙ |
| 4 | в книге «Властелин колец» | ДЕЛАЕТ |
| 5 | за картиной с Грогу | МЕНЯ |
| 6 | в Burger King из Lego | СЧАСТЛИВЫМ |

Записка должна быть **находимой, но не на виду**: под подушкой, в кармане куртки,
между книгами, под салфеткой. Не прячьте так, чтобы пришлось двигать мебель.

Важно: она не должна найти записку № 3 раньше времени. Если это возможно —
прячьте дальние главы в места, куда она не пойдёт просто так.

## Шаг 4. Спрятать подарок

Положите подарок в место из `meta.giftPlace` — под крышку, которая закрывает
клавиши фортепиано. Последняя записка лежит отдельно, в Burger King из Lego:
слово с неё вводится на сайте, после чего открывается финал с настоящим местом
подарка.

Так подарок не находится случайно раньше времени: до самого финала она видит
только записки, а место подарка появляется на экране последним.

## Шаг 5. Проверить перед вручением

1. В `js/config.js` поставьте `meta.demo: false`.
2. Откройте сайт с `?reset=1` — прогресс обнулится.
3. Пройдите квест целиком **на телефоне**, вводя слова с реальных записок.
4. Убедитесь, что:
   - все ответы принимаются (регистр и «ё» не важны);
   - слова на записках совпадают с `reward.key`;
   - каждое место описано так, что его можно найти;
   - финальная фраза читается правильно;
   - `meta.giftPlace` указывает на настоящий тайник.

## Как это выглядит для неё

1. Открывает ссылку, видит поздравление, нажимает «Начать».
2. Решает задание на телефоне.
3. Читает подсказку, идёт искать записку.
4. Возвращается, нажимает «Я нашла записку» и вводит слово.
5. Если не сходится — есть подсказка (появляется после трёх попыток).
6. После последнего слова открывается финал: фраза, письмо и место подарка.

Ориентировочно 15–25 минут, если не спешить.

## Если что-то пошло не так

**Она закрыла вкладку.** Прогресс сохранён: при следующем открытии будет кнопка
«Продолжить · глава N». Ничего не потеряется.

**Забыла, где искала.** На экране ввода ключа есть строка «Где искать» с той же
подсказкой.

**Слово не принимается.** Проверьте написание на записке и в `reward.key`.
Регистр, лишние пробелы и «ё/е» не важны — всё остальное важно.
Можно добавить варианты: `key: ["ДЕНЬ", "ДЕНЁК"]`.

**Нужно начать заново.** Откройте сайт с `?reset=1`.

**Надо проверить отдельную главу.** `?level=3` открывает третью главу сразу,
а предыдущие ключи считаются найденными.

## Про приватность

Сайт статический, поэтому все ответы и слова лежат в `js/config.js` открыто:
любой, кто откроет исходный код страницы, их увидит. Для домашнего квеста это
обычно нормально. Но если хотите снизить шанс случайного подсматривания:

- не публикуйте ссылку в соцсетях и не давайте её заранее;
- используйте неочевидный адрес (например, отдельный репозиторий с длинным именем);
- в `index.html` уже стоит `noindex, nofollow` — поисковики страницу не проиндексируют;
- при желании слова-ключи можно закодировать (например, хранить в base64) —
  это защита от любопытного взгляда, но не настоящая безопасность.
