# Разбор прошлогодней версии и решения 2026

## Что было в 2025

Репозиторий: `Zeka3535/happybirthday`, один файл `index.html` (~20 КБ, ~500 строк).

Структура: один стеклянный экран, внутри которого сменялись 4 уровня.

1. Вопрос про друга Губки Боба (ответ: Патрик), подсказка «Ищи у Ботаника».
2. Вопрос про пиццерию (ответ: Доминос), подсказка «В Соколе найдёшь».
3. Memory: 6 пар иконок (дом, кольцо, кот, самолёт, лампа, сердце).
4. Финальный босс — крестики-нолики, затем главный приз «в диванах, которые как инь-янь».

Что работало хорошо:

- Линейная структура: испытание → подсказка → следующий уровень.
- Крупные кнопки, один экран, минимум отвлечений.
- Эффект «подарок найден» с конфетти.
- Весь контент в одном месте (`levels`), легко было править.

Что стоило улучшить:

- Всё в одном файле: стили, игры и контент перемешаны.
- Жёсткая фиксированная ширина карточки и `user-scalable=no` — плохо для маленьких экранов и доступности.
- Нет сохранения прогресса: случайное обновление страницы — и всё сначала.
- Нет звука, тактильной отдачи, нормальных переходов между экранами.
- ИИ в крестиках-ноликах играет идеально — можно застрять.
- Ответы сравнивались без нормализации: лишний пробел или «ё» ломали ввод.
- Нет финального экрана с благодарностью и картой всех подсказок.
- Две механики «вопрос-ответ» подряд.
- Дизайн яркий, но универсальный; не ощущается как личная история.

## Концепция 2026: один подарок, шесть ключей

Подарок один. Но чтобы добраться до него, нужно пройти цепочку:

```
задание на сайте → подсказка, где искать → записка со словом в квартире
        ↑                                              │
        └──────── ввод слова на сайте ←────────────────┘
```

Каждое найденное слово — часть фразы. В финале из слов складывается предложение
(например, «КАЖДЫЙ ДЕНЬ С ТОБОЙ ДЕЛАЕТ МЕНЯ СЧАСТЛИВЫМ»), рядом — письмо
и место подарка.

Почему так:

- Подарок один — не нужно придумывать шесть подарков.
- Квест выходит из телефона в квартиру: она реально ходит, ищет, возвращается.
- Слово с записки нельзя угадать — нужен физический поиск.
- Фраза даёт эмоциональный финал, а не просто «молодец».
- Главы можно менять местами, убирать, добавлять — количество берётся из конфига.

Визуальный тон: тёмная ночь с золотыми звёздами и тёплой кремовой карточкой.
Крупная типографика, много воздуха, аккуратные анимации, всё читается одной рукой.

## Что реализовано

- Мобильный адаптивный layout (safe-area, `100dvh`, крупные тач-зоны).
- Шесть разных механик: огоньки, пятнашки, кодовые диски, созвездие, лабиринт, звёзды.
- Экраны: интро → задание → подсказка «где искать» → ввод ключа → финал.
- Двухшаговая награда: сначала место, потом поле для слова. Так форма влезает
  на экран 320×568 и не выглядит как «введи ответ, не сходя с места».
- Проверка ключа с нормализацией (регистр, «ё», пробелы, пунктуация).
- Подсказка к ключу после трёх неудачных попыток.
- Фраза из ключей и место подарка в финале.
- Прогресс-точки, сохранение в `localStorage` (главы + ключи), продолжение после закрытия.
- Звуки на Web Audio без файлов, вибрация, переключатель звука.
- Звёздный фон и конфетти на canvas, поддержка `prefers-reduced-motion`.
- Печатные записки `docs/notes.html` + шпаргалка организатора.
- Демо-контент с явным значком «демо», отключается одним флагом.

## Что нужно от заказчика (контент)

1. Сколько глав (сейчас 6) и какие механики в них.
2. Места в квартире: куда идти после каждой главы.
3. Слова на записках — так, чтобы складывалась фраза.
4. Где лежит подарок.
5. Финальный текст и подпись.
6. Нужны ли фото, музыка, QR-коды.

## Запас механик на будущее

- Скратч-карта (стереть слой пальцем).
- Пазл из фото.
- «Найди отличия» на фото.
- Ребус из эмодзи.
- Таймер/гонка (не рекомендуется: лишний стресс).

## Технические заметки

- Никакой сборки: классические `<script>`, работает даже при открытии файла напрямую.
- Все тексты экранируются при вставке в HTML.
- Каждая игра сообщает движку об успехе через `onSolve`.
- Прогресс: ключ `hb2026.progress.v1`, поля `index`, `completed`, `keys`, `sound`.
- Слово-ключ сравнивается через `QU.normalize`.
- Для проверки: `?level=1..N`, `?reset=1`, `?demo=1`.
- Перед публикацией: `meta.demo = false`, заменить демо-тексты.
