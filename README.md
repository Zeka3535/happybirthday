# Квест на день рождения · 2026

Новая версия интерактивного квеста для жены. Мобильный веб-сайт, открывается в браузере телефона.
Без сборки и зависимостей — чистые HTML/CSS/JS, готово к GitHub Pages.

## Быстрый старт

1. Откройте `index.html` в браузере (можно просто двойным кликом).
2. Для проверки на телефоне в той же Wi-Fi сети запустите локальный сервер:

```powershell
cd C:\Users\evgen\Downloads\happybirthday-2026
python -m http.server 8080
```

Затем откройте `http://<IP-компьютера>:8080` на телефоне.

## Как менять контент

Почти всё редактируется в одном файле — `js/config.js`.

- `QUEST.meta` — заголовки, вступление, финальный текст, подпись.
- `QUEST.levels` — уровни квеста по порядку.
- У каждого уровня есть `type`:
  - `quiz` — текстовый вопрос, ответы в массиве `answers`;
  - `lock` — кодовый замок, код в `code`;
  - `memory` — игра «найди пары», пары в `pairs`;
  - `word` — собрать слово из букв, слово в `word`;
  - `ttt` — крестики-нолики с добрым ИИ.
- `hint` — подсказка по кнопке (не раскрывает ответ, а направляет).
- `reward` — то, что появляется после уровня: заголовок, текст подсказки, где искать подарок, необязательное фото.

### Важно перед вручением

В `js/config.js` найдите `meta.demo: true` и поставьте `false` — исчезнет значок «демо».
Проверьте, что все демо-тексты и ответы заменены на настоящие.

## Полезные параметры URL

- `?reset=1` — сбросить прогресс и начать заново.
- `?level=3` — сразу открыть уровень 3 (для проверки).
- `?demo=1` — принудительно показать значок демо.

## Прогресс

Прогресс сохраняется в `localStorage` браузера. Если закрыть вкладку, при следующем
открытии можно продолжить с того же уровня. Кнопка «Пройти ещё раз» в финале сбрасывает прогресс.

## Публикация

Проект — статический сайт. Достаточно залить содержимое папки в репозиторий
и включить GitHub Pages (branch `main`, папка `/`).
