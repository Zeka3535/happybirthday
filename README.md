# Квест на день рождения · 2026

Интерактивный квест для жены: **один подарок**, спрятанный в квартире, и цепочка
из заданий на телефоне, записок в квартире и слов-ключей.

Мобильный сайт без сборки и зависимостей — чистые HTML/CSS/JS, готов к GitHub Pages.

## Быстрый старт

```powershell
cd C:\Users\evgen\Downloads\happybirthday-2026
python -m http.server 8080
```

Откройте `http://127.0.0.1:8080/`. Для проверки на телефоне в той же Wi-Fi сети —
`http://<IP-компьютера>:8080`.

Можно открыть и просто двойным кликом по `index.html`, но локальный сервер удобнее:
по нему же печатаются записки.

## Как проходит квест

```
задание на сайте → подсказка, где искать → записка со словом в квартире
        ↑                                              │
        └──────── ввод слова на сайте ←────────────────┘
```

В финале из найденных слов складывается фраза, рядом — письмо и место подарка.

Подробная инструкция по подготовке: **`docs/SETUP.md`**.
Записки для печати: `http://127.0.0.1:8080/docs/notes.html`.

## Как менять контент

Почти всё редактируется в одном файле — `js/config.js`.

### Вступление и финал

- `QUEST.meta.hero*` — экран приветствия.
- `QUEST.meta.final*` — заголовок, письмо, подпись.
- `QUEST.meta.giftPlace` — где лежит подарок (показывается в финале).
- `QUEST.meta.keyLock` — все подписи на экране ввода ключа.

### Главы

`QUEST.levels` — массив глав по порядку. У каждой есть `type`:

- `fireflies` — повтори порядок огоньков, длина в `steps`;
- `sliding` — пятнашки 3×3;
- `disks` — повернуть три диска до нужных символов (`symbols`, `target`);
- `constellation` — соединить звёзды по номерам (`stars`);
- `maze` — провести сердечко по лабиринту (`grid`);
- `stars` — поймать звёзды, сколько нужно — в `goal`.

`hint` — подсказка по кнопке внутри задания.

### Записка и ключ

```js
reward: {
    label: "Ключ 1 из 6",
    title: "Первый тайник",
    text: "Ищи там, где начинается твоё утро.",   // куда идти
    note: "На записке одно слово.",                // пояснение
    key: "КАЖДЫЙ",                                 // слово с записки
    keyHint: "С этого слова начинается фраза."
}
```

- `key` может быть массивом вариантов: `["ДЕНЬ", "ДЕНЁК"]`.
- На записке может быть два слова (`"С ТОБОЙ"`) — тогда на сайте нужно ввести оба.
- Регистр, пробелы и знаки препинания не важны: `с тобой` и `СТОБОЙ` подойдут.
- Если у главы **нет** `key`, записка не нужна: после задания сразу появится «Дальше».
- Слова всех глав складываются в фразу в финале — делайте их осмысленными.

### Важно перед вручением

В `js/config.js` найдите `meta.demo: true` и поставьте `false` — исчезнет значок «демо».
Проверьте, что все демо-тексты, ответы и слова заменены на настоящие.

## Полезные параметры URL

- `?reset=1` — сбросить прогресс и начать заново.
- `?level=3` — сразу открыть главу 3 (предыдущие ключи считаются найденными).
- `?demo=1` — принудительно показать значок демо.

## Прогресс

Сохранение в `localStorage` браузера: главы, найденные ключи, звук.
Если она закроет вкладку во время поиска записки, при следующем открытии
появится «Продолжить · глава N» и тот же экран с ключом.

## Публикация

Проект — статический сайт. Достаточно залить содержимое папки в репозиторий
и включить GitHub Pages (branch `main`, папка `/`).

Локальный git-репозиторий уже создан, первый коммит сделан. Когда контент будет готов:

```powershell
cd C:\Users\evgen\Downloads\happybirthday-2026
git add -A
git commit -m "Настоящий контент квеста"
git remote add origin https://github.com/<логин>/happybirthday.git
git push -u origin main
```

Если используете старый репозиторий `Zeka3535/happybirthday`, новый проект заменит
прошлогодний `index.html`.

Помните: все ответы лежат в `js/config.js` открыто. Для домашнего квеста это
нормально, но ссылку лучше не публиковать заранее. Подробнее — в `docs/SETUP.md`.
